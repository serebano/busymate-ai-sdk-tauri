# tauri-plugin-busymate-ai 1.0.0

Official Busymate AI SDK for Tauri v2: the hosted chat in its own webview
window, the identity bridge (wire v2, build 2.0.0) answered by your app's Rust
side, and the tap-triggered microphone adapter (wire 1, adapter 1.0.0).

Install from the tagged source or the release `.crate` — nothing is published to
crates.io. Full guide: <https://github.com/serebano/busymate-ai-sdk-tauri>.
